# PlanPilot: Subscription Management Dashboard

A full-stack SaaS admin dashboard where users subscribe to plans, track their active plan and usage, and manage their profile, with an analytics dashboard for admins.

- `client/`: React + Vite + Tailwind CSS + Redux Toolkit
- `server/`: Node.js + Express + MongoDB (Mongoose)

Setup instructions, screenshots and the full feature list will be added as the project comes together.
